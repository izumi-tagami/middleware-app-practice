# middleware-app-practice

## 概要
COACHTECH 教材 Tutorial 10-2「ミドルウェア ハンズオン演習」で作成した成果物です。
カスタムミドルウエアを作成して管理者専用ページへのアクセス制御を実装しました。

## 使用技術
- PHP 8.x
- Laravel 10.x
- カスタムミドルウェア
- Laravel Fortify（認証）
（**他に使ったものがあれば追記してください**）

## 学んだこと
- 生成したミドルウエアに管理者でなければ403を返す方法。
- ミドルウエアにAdminを登録してLarabelで認識。
- ルートへミドルウェア適用方法　->middleware('admin')

## 動作確認
http://localhost/　へアクセスし、用意されていたログイン画面から一般ユーザーでログインし【管理者ページにアクセス】で403が表示されれば成功。
